# Vendedor Pro — 100+ Frases de Fechamento de Vendas de Uniformes

Landing page de alta conversão desenvolvida para o infoproduto e playbook digital **Vendedor Pro: 100+ Frases Prontas para Fechamento de Vendas de Uniformes**.

## 🚀 Funcionalidades
- **Simulador Interativo de Objeções**: Test-drive de scripts com explicações psicológicas de persuasão para WhatsApp e balcão.
- **Calculadora Dinâmica de Perdas Financeiras**: Sliders em tempo real para estimar receitas perdidas e potencial de recuperação.
- **Showcase dos 6 Módulos & 3 Bônus**: Apresentação visual da oferta e entregáveis.
- **Design System Premium**: Dark mode corporativo com acentos esmeralda/ouro, microinterações e 100% responsivo.
- **Garantia Blindada de 7 Dias & FAQ Acordeão**.

## 🛠️ Tecnologias
- HTML5 Semântico
- Vanilla CSS moderno (Glassmorphism, Variáveis CSS, Flexbox/Grid)
- JavaScript modular puro
- Google Fonts (*Outfit* e *Plus Jakarta Sans*)

## 📦 Como rodar localmente
Clone o repositório e abra o arquivo `index.html` em qualquer navegador ou inicie um servidor local:
```bash
python -m http.server 8080
```
Acesse `http://localhost:8080`.
